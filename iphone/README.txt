iPhone (free):
1. Install "Userscripts" from the App Store.
2. Settings > Safari > Extensions > Userscripts > turn ON, allow breadfast.com.
3. Open Userscripts app > choose a folder in Files (iCloud Drive) > copy FP-Performance.user.js into that folder.
4. Open https://www.breadfast.com/dashboard/controlRoom in Safari, log in, the FP button appears.
